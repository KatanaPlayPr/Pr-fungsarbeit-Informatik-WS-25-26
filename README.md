Kurzbeschreibung des Programms / Short programm description:

Dieses Programm ist eine interaktive Studentendatenbank, mit der Studentennoten gespeichert, neue Schüler hinzugefügt und entfernt sowie Namen, IDs und Noten geändert werden können. Es arbeitet außerdem mit einer Benutzerdatenbank und ermöglicht das Hinzufügen und Entfernen von Benutzern sowie das Ändern von Passwörtern und Benutzernamen. Bestimmte Benutzer können von bestimmten Aktionen ausgeschlossen werden (z. B. darf nur Admin Benutzer hinzufügen oder entfernen, nur Lehrer Studenten usw.). Alle Daten werden lokal in entsprechenden JSON-Dateien gespeichert.

/
        
This program is an interactive students database, which allows to store student grades, add new students, remove students, change their names, IDs and grades and much more. It also works with a user database and allows to add and remove users, change password and users' usernames. It also restricts some user from some actions (e.g., only Admin user may add or remove users, only teacher may add or remove students and so on). All data are stored locally in corresponding JSON files.

.
